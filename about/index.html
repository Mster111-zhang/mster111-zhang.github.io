个人简介

我是张艺豪，目前在东北林业大学读计算机技术硕士，预计 2028 年毕业。我的课题围绕心脏 MRI 分割，希望从影像结构进一步提取能够描述心室功能的指标。

我也在学习 Agent 工作流和知识问答，关注如何把模型接到工具和已有业务系统上。我本科做过 Java 后端开发，参与过智慧停车项目，也做过公共卫生健康档案系统。
