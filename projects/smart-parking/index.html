智慧停车管理系统

参与智慧停车系统开发，使用 MVC 组织业务代码，通过 MySQL 事务保障数据一致性。

实习项目

在北京华育兴业科技有限公司哈尔滨分公司实习期间，我参与了智慧停车管理系统开发。项目使用 Spring Boot、MySQL、JSP、Tomcat 和百度地图 SDK。

我做了什么

按 MVC 划分页面交互、业务逻辑和数据访问，使用 Spring Boot 整合配置。在业务写入涉及多步操作的场景中，使用 MySQL 事务保障原子性和一致性。
