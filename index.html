基于心脏 MRI 的心肌功能评估

从心脏 MRI 中分割左心室、右心室和心肌。我重点比较模型在心肌薄壁和心室边界上的表现，再用分割结果估算心室容积与射血分数。

PythonPyTorchU-NetACDCDice / HD95
当前进展完成五类模型的首轮基准训练与验证，已实现预测可视化、实验报告导出及心功能计算原型。
展开实验方法与评估
  • 统一影像预处理、空间几何对齐和患者级数据划分，用同一实验流程对比模型。
  • 围绕改良 U-Net 探索内容感知上采样与多尺度语义融合，开展结构筛选和模块对照。
  • 用 Dice 衡量区域重叠，用 HD95 衡量边界距离，再回看逐病例误差定位典型失败样本。

自然语言查数与图表生成

我独立搭建并接通了从自然语言提问到 SQL 查询、结果解释和图表展示的工作流。以成绩统计为例，用户输入「查询全年级平均成绩」，即可看到分年级汇总与对比柱状图。

Text-to-SQLDify ChatflowMySQLECharts
  1. 自然语言提问
  2. 生成并解析 SQL
  3. 执行 MySQL 查询
  4. 汇总与图表输出
展开实现细节
  • 模型生成 SQL，代码节点解析查询语句，迭代节点调用 MySQL 执行并整理返回的数据。
  • 模型根据查询结果生成文字摘要，再构造 ECharts 参数，由条件分支决定输出折线图、柱状图或饼图。
