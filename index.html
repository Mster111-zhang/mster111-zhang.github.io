关于我

你好，我是张艺豪，东北林业大学计算机技术研究生，预计 2028 年毕业。我正在研究如何从心脏 MRI 中分割心室和心肌，并用分割结果计算心室容积与射血分数。

我也在学习大模型 Agent 应用开发，做过 Agent 学习 Demo，接触过 Dify、LangChain、LangGraph 工作流和 RAG。此前做过 Java 后端开发，有 Spring Boot、RESTful API 和 MySQL 的项目经验。

项目

硕士研究课题 · 2025.12 至今

基于心脏 MRI 的心肌功能评估

用 Python 和 PyTorch 搭建分割实验流程，自动分割左心室、右心室与心肌，并在 ACDC 数据集上完成五类模型的首轮基准训练与验证。

目前探索改良 U-Net 对心肌薄壁和心室边界的处理，用 Dice、HD95 和逐病例分析评估分割效果，并开发了心室容积与射血分数的计算原型。
