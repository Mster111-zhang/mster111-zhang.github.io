关于我

你好，我是张艺豪，东北林业大学计算机技术研究生，预计 2028 年毕业。我正在研究如何从心脏 MRI 中分割心室和心肌，并用分割结果计算心室容积与射血分数。

除了研究，我也在学习怎么把大模型接入真实的应用流程。我接触了 Dify、LangChain 和 LangGraph，做过多个练习 Demo，并学习了 RAG 的检索、生成与效果评估。此前的 Java 后端项目让我熟悉了业务接口与数据库这两部分，学习 Agent 时，我也会关注它怎样和已有系统对接。

硕士研究课题 · 2025.12 至今

基于心脏 MRI 的心肌功能评估

从心脏 MRI 中分割左心室、右心室和心肌，再用分割结果估算心室容积与射血分数。我的工作覆盖数据准备、分割实验和功能量化原型。

查看研究过程

数据与基准　用 Python 和 PyTorch 搭建实验框架，完成预处理、空间几何对齐和患者级划分。按患者划分能让同一患者的数据留在同一集合。已完成 ACDC 上五类模型的首轮基准训练与验证。

模型改进　针对心肌薄壁和心室边界，探索内容感知上采样与多尺度语义融合，开展结构筛选和模块对照分析。

评估与输出　用 Dice 衡量分割区域的重叠程度，用 HD95 衡量边界偏差，并结合逐病例误差查看失误集中在哪些样本。实验流程支持预测可视化和报告导出，也已实现心室容积与射血分数的计算原型。
